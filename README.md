# Laundry Services Hero Section

## Project Title
CSS - Laundry Services Hero Section

## Description
This project is a responsive Laundry Services Hero Section created using HTML and CSS.

The webpage contains a navigation bar and a hero section for a laundry service website. The hero section includes a heading, description, call-to-action button, and a laundry-related image.

## Features

- Responsive navigation bar
- Logo and user name
- Home, Services, About Us and Contact Us links
- Hero section with two divisions
- Laundry service heading and description
- "Book a Service Today" button
- Laundry-related image
- Responsive design for mobile devices
- Viewport units are used for sizing
- CSS positioning properties are used
- Flexbox is not used
